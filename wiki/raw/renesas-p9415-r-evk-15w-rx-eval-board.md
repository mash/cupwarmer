# Renesas P9415-R-EVK 15W Receiver Evaluation Board

- Source: [P9415-R-EVK - Evaluation Board for 15W Wireless Power Receiver with WattShare Mode | Renesas](https://www.renesas.com/en/design-resources/boards-kits/p9415-r-evk)
- Accessed: 2026-04-11

## Notes

- `P9415-R-EVK` は `15W` wireless power receiver evaluation board。
- `Qi Extended Power Profile (EPP)` transmitter から `up to 15W` を受電。
- `thin profile receiver coil (0.3mm)` を使用。
- `schematics, layout files, BOM` を含む turnkey reference design。
- `Embedded 32-bit ARM Cortex-M0 processor`。
- `Obsolete`。

## Relevance

- 量産候補というより、`15W` 構成の現実感を掴むための参照設計。
- `WLCSP` を自分で直接実装したくない場合の学習素材としては有用。
