# KiCad Schematic Edit

## What kiutils CAN do

| Operation | Method | Notes |
|-----------|--------|-------|
| Modify symbol properties (Value, Reference) | kiutils | Safe, roundtrip-clean |
| Add/remove schematic symbols (components) | kiutils | Clone from existing with `copy.deepcopy()` |
| Add/remove wires (Connection) | kiutils | Set `stroke = Stroke(width=0, type="solid")` |
| Add/remove labels (GlobalLabel) | kiutils | Clone from existing to get correct Justify object |
| Move components (change position) | kiutils | Wires must be redrawn to match new pin positions |
| Add pins to lib_symbols | kiutils | Add to both .kicad_sch lib_symbols and .kicad_sym |
| Add pins to cupwarmer.kicad_sym | kiutils | Keep in sync with embedded lib_symbols |

## kiutils Setup

```python
import sys
sys.path.insert(0, "/Users/mash/src/github.com/mvnmgrx/kiutils/src")
from kiutils.schematic import Schematic

```

## Coordinate System

KiCad 10 uses Y-inverted mapping from symbol to schematic:

```
schematic_x = symbol_center_x + pin_symbol_x
schematic_y = symbol_center_y - pin_symbol_y   ← Y is NEGATED
```

Use `skills/kicad-schematic-edit/scripts/pin_calc.py` for pin position calculations:

```python
from pin_calc import pin_schematic_pos, passive2_pins

# U1 at (106.68, 63.5), pin AC1 at symbol (-12.7, 5.08)
x, y = pin_schematic_pos(106.68, 63.5, 0, -12.7, 5.08)
# -> (93.98, 58.42)

# PASSIVE_2 component at (cx, cy, angle)
p1x, p1y, p2x, p2y = passive2_pins(cx, cy, angle)
```

For rotated components (angle=90):
- Pin1 at symbol (-5.08, 0) → schematic (cx, cy+5.08)  [bottom]
- Pin2 at symbol (5.08, 0)  → schematic (cx, cy-5.08)  [top]

## Adding Wires

```python
from kiutils.items.schitems import Connection
from kiutils.items.common import Position, Stroke

w = Connection()
w.points = [Position(X=round(x1,2), Y=round(y1,2)),
            Position(X=round(x2,2), Y=round(y2,2))]
w.stroke = Stroke(width=0, type="solid")  # REQUIRED for connectivity
sch.graphicalItems.append(w)
# UUID is auto-generated by kiutils
```

Always `round()` calculated coordinates to 2 decimal places to avoid float precision issues.

## Adding Labels

Clone from an existing label — do NOT construct from scratch (Justify object issues):

```python
import copy
gl = copy.deepcopy(existing_label)
gl.text = "MY_NET"
gl.shape = "passive"  # or "bidirectional" for I2C
gl.position = Position(X=x, Y=y, angle=0)
gl.effects = copy.deepcopy(existing_label.effects)
gl.effects.justify = Justify(horizontally="left", vertically=None, mirror=False)
sch.globalLabels.append(gl)
# UUID is auto-generated
```

## Adding Components

Clone from an existing component of the same lib_id:

```python
import copy, uuid as uuid_mod

s = copy.deepcopy(template_symbol)
s.position = Position(X=cx, Y=cy, angle=angle)
s.uuid = str(uuid_mod.uuid4())
for p in s.properties:
    if p.key == "Reference": p.value = "C99"; p.position = Position(X=cx, Y=cy-3.81)
    elif p.key == "Value": p.value = "100nF"; p.position = Position(X=cx, Y=cy+3.81)
s.pins = {"1": str(uuid_mod.uuid4()), "2": str(uuid_mod.uuid4())}
s.instances = [SymbolProjectInstance(name="cupwarmer-hw",
    paths=[SymbolProjectPath(
        sheetInstancePath="/f3c63676-f392-4700-9f58-a6787e1eb284/11111111-1111-1111-1111-111111111111",
        reference="C99", unit=1)])]
sch.schematicSymbols.append(s)
```

## Adding Pins to Symbols (RAW TEXT ONLY)

**Do NOT use kiutils** for adding pins to `lib_symbols`. kiutils reformats the `lib_symbols` section, which breaks KiCad's pin connectivity for newly added pins (existing pins survive roundtrip, new ones don't).

Use raw text matching the existing format in the file:

```python
with open(filepath) as f:
    content = f.read()

new_pin = """\t\t\t\t(pin passive line
\t\t\t\t\t(at -12.7 -10.16 0)
\t\t\t\t\t(length 5.08)
\t\t\t\t\t(name "VS"
\t\t\t\t\t\t(effects
\t\t\t\t\t\t\t(font
\t\t\t\t\t\t\t\t(size 1.27 1.27)
\t\t\t\t\t\t\t)
\t\t\t\t\t\t)
\t\t\t\t\t)
\t\t\t\t\t(number "16"
\t\t\t\t\t\t(effects
\t\t\t\t\t\t\t(font
\t\t\t\t\t\t\t\t(size 1.27 1.27)
\t\t\t\t\t\t\t)
\t\t\t\t\t\t)
\t\t\t\t\t)
\t\t\t\t)"""

# Insert before a known marker (e.g., VRECT pin or unit close)
content = content.replace(marker, new_pin + "\n" + marker)
```

**Also update `cupwarmer.kicad_sym`** with the same pin (different indentation level).

Pin instance refs in U1 can be added via raw text:

```python
pin_ref = '\t\t(pin "16"\n\t\t\t(uuid "...")\n\t\t)\n'
content = content.replace(u1_instances_marker, pin_ref + u1_instances_marker)
```

## Structural Rules

Keep coherent: `sheet` entries, `sheet_instances`, `symbol.instances.project.path`, `global_label` connectivity.

High-risk — never duplicate or reassign: `uuid`, `sheet_instances`, `instances`, pin UUIDs.

Do not rename references (`U1`, `Q1`, `C1`, `L1`) unless explicitly asked.

## Target Files

- Top-level: `hardware/kicad/cupwarmer-hw/cupwarmer-hw.kicad_sch`
